当前仍是 `1.0.0-dev`，不是 v1.0 正式发布。正式发布门槛见[发布准备](release-v1.0.md)；已发布 v0.4.0 的资产不变。测试全部使用独立合成商品、用户和资金，不加载商家 `.env`，不向真实支付服务或 Telegram 用户发送压测流量。

### 同一买家的跨功能旅程

新增 `TestTelegramReleaseJourney`，两种数据库均执行，不仅分别测试页面：

1. 充值到账 100.00，实付 103.50；错签名不入账，成功与重复回调后余额 100.00、仅一条充值流水。
2. 直输两件人工商品，纠正邮箱与优惠码，保留购买资料；旧确认不能下单。新确认按 19.00 余额支付，重复按钮不重复扣款，剩余 81.00。
3. 真实后台核对表单资料并完成人工交付，通知直达 TXT。
4. 购买两件自动商品，在线付款 6.50；继续支付复用原链接，重新显示付款码不建新单；回调后两张卡密完整交付。
5. 重启后按订单号查找，带编号打开客服草稿；返回下载不重复发文件，最终仍两张订单、两个支付网关记录、两份 TXT、一次优惠码使用、余额 81.00。审计不含邮箱、优惠码或交付原文。

表单与优惠码回复遵循真实 Telegram ForceReply 的 `reply_to_message` 关联，不绕过产品输入校验。

## 本轮发现与修正

- 钱包、订单及支付页继续统一两列分组：订单短按钮对应正文编号，完整状态不截断丢失；待支付快捷筛选、充值后回订单及支付页直达详情减少返回层级。SDK 断言覆盖主操作整行与次要操作两列，原取消/重发二次确认、用户隔离、原支付复用及资金防重不变，不因单个渠道或页面展示自动提交资金请求。
- 商品浏览与购买确认延续紧凑布局：分类/短规格两列、长名称整行，商品正文编号对应两列入口且显示会员价；数量卡主操作带件数，减/输入/加与批量快捷值保持三列，固定数量不显示无效调整；确认页工具两列、失败页只允许重试/修改不允许确认。新增三语言/空列表/映射/库存/零提前提交回归，双数据库批量数量与综合旅程断言实际 SDK 按钮，同时验证原金额、表单、优惠码及旧确认防重。
- 推广/提现/售后布局回归覆盖分享与复制同一链接、记录直达/互切、提现渠道两列/长名称整行、确认与解除保护独立、退出记录后旧确认失效、锁定态不提供快捷重提、售后问题短标签及刷新/返回并排。`TestTelegramAffiliateWithdrawal` 在双数据库独立栈通过不同合成买家真实已付订单产生佣金，经真实 Bot 输入与二次确认只创建一笔待审核提现，重复及重启不重复申请，不调用审核或打款；售后布局断言复用 `TestTelegramOrderSupport`。
- 后续真人验收发现文本输入只编辑上方旧消息，且管理员“订单创建成功”的英文事件码被误认为付款成功。开发版改为数量/充值/优惠码输入后在聊天底部给出下一步，数量错误也发送新提示；后台摘要中文化、明确管理员身份及创建/付款/交付的区别，商品注明自动/人工交付。新增严格消息顺序断言，旧历史消息不改写，仍需真人复测。
- “显示付款码”此前会因已有受跟踪图片而无动作；现在显式点击重新展示原记录，普通“继续支付”仍不重复推送，不额外创建支付。补齐跨用户/群聊/过期记录及重复支付回归。
- Mock 缺少最新支付查询，返回成功空数据会阻塞当前付款流程。补齐归属受限查询、明确缺失/关闭/过期语义及原记录复用；媒体接口返回真实 SDK 预期的 Message 对象。未重建仍保存内存数据的旧演示商店。
- 稳定版打包入口无法验证开发候选包，且公开文档清单易遗漏。增加独立候选目录、完整公开文档、二进制来源和压缩包校验；拒绝私有配置、数据、路径穿越与链接文件，不覆盖旧附件。

## 证据与边界

2026-10-20 本地 Docker Desktop ARM64 执行记录以本次交付和对应提交 CI 为准。CI 保留两种数据库的脱敏升级/E2E/90 秒冒烟负载日志，以及公开候选压缩包和 `validation.json`；本地默认负载为五分钟。测试失败必须修正并重跑，不把跳过、未运行或旧提交成功算作当前成功。

尚需人工确认：Telegram 手机/桌面客户端按钮、复制、客服预填、批量 TXT 的实际使用；独立公网测试 Bot；商家选定支付提供方的沙箱签名/金额/到账/通知闭环。当前真人 Bot 临时复用仅用于已授权的本地模拟沙箱，不是独立公网支付沙箱验收。

不承诺生产最大 TPS、长时间稳定性、全部第三方支付和自定义 fork 兼容，亦不承诺消息恰好一次。历史单次重启回调 503 缺少正文，仍不能宣称唯一根因已核实；持续严格回归与已修正的测试隧道 EOF 问题见[故障记录](operations-v1.md)。不以清 Redis、换密钥、回滚旧快照或盲目重发未决资金操作来通过验收。

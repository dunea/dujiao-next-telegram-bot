# v0.4.0 · 用户增长与轻量运营

免费开源的 Dujiao-Next 社区 Telegram 商店机器人，自托管免费，MIT 许可。

本次发布：

- 推广中心、专属邀请链接、访问/佣金面板和服务端订单归因。
- 提现申请：金额与可用佣金校验、收款信息填写、二次确认和结果不明保护；只申请审核，不自动打款。
- 可选 Redis：加密草稿、跨重启提现保护、限流额度和公告进度。
- 管理员白名单摘要、脱敏操作审计与持久轮转日志、分层限流。
- 主动订阅的纯文本公告：预览、固定受众二次确认、退订、逐条限速和重启后人工继续；不启用付费广播。
- 保留 v0.3 的商品购买、表单/优惠码、订单支付、充值手续费和礼品卡能力。

验收：三轮全量竞态回归、静态/依赖检查、Docker 构建、真实 Redis AOF/故障恢复、1000 名模拟订阅者队列以及隔离健康/回调压测通过。未向真实用户发送测试群发，未触发真实资金操作；真实商家支付渠道仍需自行测试。

下载对应平台/架构的 `.tar.gz` 并使用 `checksums.txt` 验证完整性；解压后执行 `--version` 应显示 `0.4.0`。下载包的 `build-info.txt` 可核对源码提交。程序不自动加载 `.env`，需由 Compose 或服务管理器注入环境变量。

正式使用提现或群发建议配置可靠 Redis、稳定独立加密密钥与持久卷。升级保持原项目名和数据，不运行 `down -v`；旧内存会话不会自动迁移。管理员通知不保证跨崩溃恢复，数据删除/回滚不在全局防重保证内。
